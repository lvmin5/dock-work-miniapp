# 吊机作业记录小程序

这是一个个人使用的微信小程序，用来记录码头吊机作业数据，并按日、月、年统计数量和金额。

## 功能

- 底部 4 个 Tab：录入、明细、单价、统计
- 录入机械号、装卸类型、作业类型、吉重、箱型和数量
- 装卸船、散货只显示装船和卸船；提交箱只显示装车和卸车
- 选择“散货”时，吉重只显示“粮食”
- 选择“粮食”时不需要选择箱型，数量可输入小数
- 选择“吉”或“重”时必须选择箱型，数量只能输入整数
- 选择“40尺”时，明细和统计数量仍显示录入数量，金额按 2 个标箱计价
- 明细页按表格展示日期、机械号、装卸类型、作业类型、吉重、箱型、数量，并支持点击修改
- 单价页可编辑吉、重、粮食对应单价
- 统计页可按日、按月、按年统计装卸类型和吉重，粮食按吨单独统计

## 使用方法

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹。
4. AppID 可以先选择“测试号”或使用自己的小程序 AppID。
5. 在手机预览前，先在开发者工具里确认页面显示正常。

## 数据说明

当前版本的数据保存在手机本地缓存里，不需要服务器。更换手机、清理微信缓存或卸载小程序后，本地数据可能丢失。

如果以后要多人同步、换手机不丢数据，可以再升级成微信云开发版本。
